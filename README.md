# Currency Converter

Application Android (Kotlin, View Binding) qui convertit un montant d'une devise vers une autre à partir de taux fixes (pivot EUR).

## Fonctionnalités
- Deux listes (Spinner) : devise source et devise cible
- Clavier numérique personnalisé (TableLayout 4 x 3), touche C
- Conversion via l'euro, résultat arrondi à 2 décimales
- Bouton d'inversion des devises
- Règles : un seul point décimal, 10 caractères max, Toast si le montant vaut 0, orientation portrait

## Taux (pour 1 EUR)
EUR 1.00 | USD 1.17 | TND 3.40 | GBP 0.87 | JPY 172.50 | CAD 1.62

## Technologies
Kotlin, ConstraintLayout, TableLayout, View Binding, minSdk 24

## Lancer le projet
Ouvrir dans Android Studio, synchroniser Gradle, lancer sur un émulateur.
